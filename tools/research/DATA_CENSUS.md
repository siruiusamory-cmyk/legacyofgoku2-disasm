# The data outside every container

Generated by `python tools\research\data_census.py --write`; `--check` re-derives this page from the builder's image and refuses a difference.

## Method

The measured region is the gate's own class: every byte the asm files INCBIN from the image (`gate.incbin_ranges`), less the extents of the accepted containers in `CONTAINER_CENSUS.csv`. It is 3406114 B in 5809 extents, and the container census owns the rest of the gate's raw class. Those extents hold 14304 class runs, and a class extent is one maximal run of that class inside them.

A byte is classed by the first of these rules that claims it. A **reader class** is a record family whose extents this tree already decodes, and its reader is a load site in the split's walked code (a `CODE_SPLIT.csv` code extent) that names the family's base in its literal pool; where the base is reached through a pointer and no literal names it, the reader is the decoder's own code site. A **no reader found: fill run** class is a run of at least 8 fill bytes, a **no reader found: address run** class is two or more consecutive 4-aligned words that name the image, and the **no reader found: residual** is what those rules leave.

The three non-reader classes are labelled `no reader found`: the game's code has no decoder here. They are shapes, not formats, and a shape is not a reader.

The null keeps the region's extents and permutes their bytes, reversing the halfword order inside every extent, so the same decoders run over the same address set with no byte structure left. A reader class that survives that run is not reading structure.
