# The JCALG1 container population

Generated by `python tools\compress\container_census.py --write`; `--check` re-derives this page and its CSV from the builder's image and refuses a difference.

## Method

The scan reads every 4-byte-aligned site in the image. A site is a container when its first word is a kind in 0, 1 or 2 and its second word is a declared size from 1 to 65,536 B. A kind-0 container is its 8-byte header and that many stored bytes; kinds 1 and 2 decode the JCALG1 body against the declared size and end at the body's own end code. The accepted population is the greedy left-to-right set over packed hits only: a hit is accepted when its offset is at or past the end of the previous accepted packed hit, so no accepted extents overlap and the byte union is the sum of the packed extents. A kind-0 hit never sets that edge and is never admitted; it is a shape measurement.

A kind-0 hit is a shape and not a container this population can admit: kind 0's codec is the identity, so its extent reproduces the bytes under it and is not a source class, and no consumer is established for any member. The scan still records those hits and the null still finds them; the selection refuses them. Measured here: 9037 kind-0 hits are refused in the image and 1468 in the null.

A packed hit whose stream the encoder does not reproduce is refused by name rather than counted: `0x4FE20C` (kind 1, declared 2048 B, packed 192 B).

The null permutes the image by reversing the halfword order inside every 64 KiB block, then runs the same scan and the same selection. A format found at this rate in the real image and absent from the null is measured, not fitted.

A packed extent is the body's consumed input. When a body's output completes exactly on a 4-byte boundary the decoder stops there, so the stream's end-marker word falls in the following gap; a re-encoder emits that word, and a container's encoder extent can be one word longer than the extent this census records. Where that word is the bytes the next token already carries, the generator emits the container to the decoder's extent and the next token supplies the word.

## The per-row ledger

`tools/compress/CONTAINER_CENSUS.csv` carries one row per accepted container: offset, kind, declared size, packed extent, decoded length, payload shape and the first 16 hex digits of the decoded payload's sha256. The rows are the population the totals count.
